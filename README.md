O CRM é uma plataforma de gestão de relacionamento com o cliente, de código aberto (open source), criada como uma alternativa moderna, modular e flexível a soluções como Salesforce e HubSpot.

Entre seus principais diferenciais está o código aberto, licenciado sob AGPL, que permite instalar, personalizar e hospedar a solução nos próprios servidores, garantindo maior controle sobre os dados.

A interface é moderna, limpa e intuitiva, seguindo uma experiência de uso semelhante a ferramentas de produtividade como o Notion.

Do ponto de vista técnico, oferece APIs e SDKs que permitem criar objetos personalizados, automações e fluxos de trabalho de acordo com as necessidades do negócio.

Também possui recursos de Inteligência Artificial, possibilitando a criação de interações mais inteligentes e assistentes integrados aos processos do CRM.
